# INCzytelnia - projekt zaliczeniowy w C++ na Inzynierie Oprogramowania 

Projekt na zaliczenie inzynierii oprogramowania realizujacy system informatyczny (mały backend, bez bazy danych) z jakiego mogłaby skorzystać przykładowa czytelnia.

Projekt zawiera dokumentacje UML

# Budowanie
```
git clone https://github.com/Kacper79/INCzytelnia
cd INCzytelnia
g++ *.cpp -o inczytelnia
